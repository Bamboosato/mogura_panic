# 元祖モグラパニック！ (Mogura Panic)

昭和〜平成初期の懐かしのエレメカ（エレクトロメカニカル）アーケードゲームの爽快感と、現代のシニア・子供向け「脳トレ（Go/No-Go課題・セットシフティング）」を融合した、Webブラウザで遊べる本格モグラ叩きPWAゲームです。

---

## 🎮 主なゲームモード・特徴

### 1. 王道エレメカモード
- **元祖モグラ叩き**: 穴から飛び出すモグラを素早く叩いて高得点を目指します。
- **ゴールドモグラ**: 出現時間が短く素早いが、叩くと高得点（+30点）！
- **ヘルメットモグラ**: ヘルメットを被った頑丈なモグラ。2回叩くことで撃破可能！
- **爆弾（NO-GO課題）**: 叩くとペナルティ（-20点＆コンボリセット）。叩かずに見送る抑制コントロールが重要です。

### 2. 脳トレモード（認知機能・注意力トレーニング）
- **リアルタイムお題ルール変更**: ゲーム中に突然現れる「お題」に従って、叩くモグラを瞬時に判断します。
  - **数字ルール**: 【 偶数 】、【 奇数 】、【 ５以上 】、【 ４以下 】
  - **色ルール**: 【 青色 】、【 黄色 】、【 緑色 】、【 ピンク 】
- **Grace Pause（猶予ポーズ）**: ルール変更時は約1.5秒間の自動消去ビッグポップアップとカウントダウンが発生し、落ち着いてお題を確認できます。

### 3. レトロアーケード筐体＆ジオラマ演出
- **7セグメントLEDスコアボード**: レトロな電飾スコア＆残り時間表示。
- **草原と地下トンネルジオラマ**: 
  - 盤面上部：草むらから双眼鏡で見張る「見張りモグラ」やチョウチョの地上風景。
  - 盤面下部：安全ヘルメットのヘッドライトを照らし、トロッコに乗って走る「トロッコモグラ」の地下鉱山風景。
- **サウンド演出**: Web Audio APIによるプロシージャル合成音（叩き音、ミス音、警告音、ファンファーレ）。
- **ランキング機能**: LocalStorageによるTop 10スコア履歴の自動保存・順位ハイライト表示。

---

## 🛠️ 技術スタック

- **フロントエンド**: React 19 + TypeScript + Vite
- **スタイリング**: Tailwind CSS v4
- **サウンドエンジン**: Web Audio API（外部音声ファイル非依存・完全プロシージャル合成音）
- **アニメーション**: SVG + GPU支援CSSキーフレームアニメーション
- **PWAサポート**: vite-plugin-pwa（オフライン対応・スタンドアロン全画面表示）

## 🚀 ローカル起動方法

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev

# プロダクションビルド
npm run build

# ビルドプレビュー
npm run preview
```
