# 元祖モグラパニック！（仮）Webアプリ要件定義書・詳細設計書 (v1.1)

**〜 Antigravity 実装エージェント引き継ぎ用 正式仕様書 〜**

本ドキュメントは、昭和・平成のゲームセンターで親しまれたエレメカ「モグラ叩き」の直感的な打撃感と、認知科学における「Go/No-Go課題（衝動抑制）」「セットシフティング（ルール切り替え）」「周辺視野・空間注意」を融合させた脳トレWebアプリケーション『元祖モグラパニック！（仮）』の要件定義書および詳細設計書である。

シニア層（年配者）から子どもまで誰でも迷わず快適に遊べるよう、「文字説明の最小化と大型フォント」「数字・ターゲットの超高視認性」「ルール変更時の自動消去ポップアップ（猶予ポーズ付き）」「PWA・スマホSafe Area完全全画面対応」を最優先要件として定義している。実装担当エージェント（Antigravity）は、本仕様書に従って設計・実装・検証を行うこと。

## 1. プロジェクト概要・基本方針

### 1.1 コンセプトと背景

* **エレメカの身体性 × 脳トレ**: 穴から飛び出すモグラを叩く直感的な楽しさに、「叩いてはいけないターゲット（衝動抑制）」や「途中で切り替わるお題（認知的柔軟性）」を掛け合わせる。

* **シニア・ユニバーサルデザイン**: 年配者でも老眼鏡なしで数字やルールが瞬時に判別でき、細かい説明文を読まなくても直感的に操作できるUI/UXを徹底する。

### 1.2 4大必須設計原則（最優先遵守事項）

1. **文字説明の最小化と最小フォントサイズ制限**:

   * ゲーム画面内の長文説明や細かい注釈を排除し、アイコンと短いキーワードのみで表現する。

   * 画面内のいかなるテキストも **最小16px (`1rem` / `text-base`) 以上** とし、`10px`〜`12px` の極小文字は一切使用しない。

2. **年配者でも瞬時に判別できる高視認性（ハイコントラスト）**:

   * スコア・残り時間・モグラが持つ数字プレートは、背景とのコントラスト比 **7:1〜10:1以上（WCAG AAA水準）** を確保し、極太フォント（`font-black` / `800〜900`）で大きく描画する。

3. **ルール切り替え時の「自動消去ビッグポップアップ」＆猶予ポーズ**:

   * プレイ中にルール（お題）が切り替わる際は、画面中央に**大型の自動消去ポップアップ**をオーバーレイ表示する。

   * ポップアップ表示中（約1.5秒間）はタイマーおよびモグラ出現を一時停止（Grace Pause）し、プレイヤーが焦らず新ルールを認識してから再開する仕組みとする。

4. **PWA対応 ＆ スマホSafe Area全画面固定レイアウト**:

   * スマホ画面（`100dvh` × `100vw`）に完全フィットさせ、上下左右のスクロールを一切発生させない。

   * ノッチやホームバーを考慮した `env(safe-area-inset-*)` 対応、およびホーム画面追加（スタンドアロン全画面起動）可能なPWA構成とする。

  * **現在のお題バナー**: **20px〜28px (`text-xl`〜`text-2xl`)**、文字色は純白（`#FFFFFF`）または高輝度イエロー（`#FDE047`）。

* モグラの種類による違いは、**見た目の直感的な記号**だけで伝える：

  * 通常のモグラ：茶色（笑顔）

  * 高得点モグラ：金色＋王冠 👑

  * 2回叩くモグラ：黄色い安全ヘルメット ⛑️（1回叩くとヘルメットが吹き飛ぶアニメーション）

  * 叩いてはいけないキャラ：黒いトゲ爆弾 💣＋赤い「×」マーク

## 4. ルール切り替え演出（自動消去ポップアップ）仕様

プレイ中にルール（お題）やフェーズが変化する際、年配者でも「いまルールが変わったこと」と「次に何を叩けばよいか」を確実に認識できるよう、以下の**自動消去ポップアップ＆一時猶予シーケンス**を実装する。

### 4.1 ポップアップUI構造（`RuleSwitchPopup`）

* **表示位置**: プレイフィールド中央を覆う大型オーバーレイカード（`z-index: 50`、背景は `bg-slate-950/85 backdrop-blur-sm`）。

* **カードデザイン**:

  * 枠線：4px〜6pxのネオン発光ボーダー（ルール変更時はシアン `#22d3ee`、パニックタイム突入時はレッド `#ef4444`）。

  * 上段バッジ：`⚡ ルール変更！`（`text-xl font-black text-amber-300`）

  * 中段メイン指令（特大）：`次は【 奇 数 】を叩け！`（`text-3xl sm:text-4xl font-black text-white`）

  * 下段視覚サンプル：対象となる数字例（例：`1, 3, 5, 7, 9`）やアイコンを大きく並列表示。

  * **閉じるボタンは設けない（完全自動消去）**。

### 4.2 ルール切り替え時のタイムライン制御（Grace Pause）

ルール変更の瞬間にモグラが出っぱなしだと「旧ルールで叩こうとした指が止まらずお手つきになる」という理不尽なストレスが生じるため、以下の4ステップで進行を制御する：

1. **Step 1 (0.0s): ゲーム一時ポーズ＆全モグラ収納**

   * ゲーム残り時間タイマー（`gameTimer`）と新規出現タイマー（`spawnTimer`）を一時停止（`isRuleSwitching = true`）。

   * 現在顔を出しているすべてのモグラを即座に穴へ引っ込める（ペナルティなし）。

2. **Step 2 (0.0s〜0.2s): ポップアップ表示＆効果音再生**

   * 画面中央に `RuleSwitchPopup` をポップインアニメーション（`scale(0.8) ➔ scale(1.0)`）で表示。

   * 明確なルール切り替えチャイム音（「ジャジャーン！」または「ピロリロリン♪」）を再生し、上部のお題バナーも新ルールへ更新。

3. **Step 3 (0.2s〜1.6s): 認識猶予時間（1.4秒間ホールド）**

   * プレイヤーが新しいお題を目で見て頭を切り替えるための猶予時間を確保。

   * ポップアップ下部に縮小していくプログレスバーを表示し、あとどれくらいで再開するかを視覚的に伝える。

4. **Step 4 (1.6s〜1.8s): 自動フェードアウト＆ゲーム再開**

   * ポップアップが自動でフェードアウト消去（`opacity: 0`）。

   * `isRuleSwitching = false` に戻し、残り時間タイマーと新ルールでのモグラ出現を再開する。

## 5. ゲームモード・メカニクス詳細仕様

### 5.1 モード構成（2モード搭載）

ヘッダーまたはスタート画面の大きなトグルボタンで、以下の2モードをワンタップで切り替え可能とする。

#### ① 王道エレメカモード（反射神経 ＆ Go/No-Go抑制）

* 数字計算はなく、穴から飛び出すモグラをテンポよく叩くモード。

* **ターゲット構成**:

  * **普通モグラ**: 1回叩くと `+10点`

  * **黄金モグラ 👑**: 出現時間が短いが `+30点`

  * **ヘルメットモグラ ⛑️**: 1回目でヘルメットが外れ（`+5点`）、2回目で撃破（`+20点`）

  * **トゲ爆弾 💣（No-Goターゲット）**: 叩くと爆発し `-20点` ＆ コンボリセット。叩かずに見送ると「ナイス回避！」として内部評価加算。

* **パニックタイム（残り15秒）**:

  * 残り15秒で自動消去ポップアップ『🔥 もう怒ったぞ！パニックタイム！』が1.5秒間表示され、後半の高速ラッシュに突入する。

#### ② 脳トレ・ルールシフトモード（暗算・判断 ＆ 思考切り替え）

* すべてのモグラが胸元に特大の「数字プレート（1〜9）」または「色バッジ」を持って出現する。

* 1試合（45秒または60秒）の間に、**15秒ごと（計3〜4回）にお題が自動ポップアップで切り替わる**。

* **お題プール（ステージ・難易度に応じて出題）**:

  1. `【 偶 数 】を叩け！` （対象：2, 4, 6, 8）

  2. `【 奇 数 】を叩け！` （対象：1, 3, 5, 7, 9）

  3. `【 5以上 】を叩け！` （対象：5, 6, 7, 8, 9）

  4. `【 4以下 】を叩け！` （対象：1, 2, 3, 4）

  5. `【 3の倍数 】を叩け！` （対象：3, 6, 9）

  6. `【 足して10になる数 】を叩け！`（例：お題に「＋3」と表示されていたら「7」のモグラを叩く）

* 条件に合致するモグラを叩けば `+20点`、条件外のモグラを叩くとお手つき（`-10点` ＆「× お手つき！」ポップ表示）。

### 5.2 速度プリセット（年配者配慮の3段階スピード）

プレイヤーの年齢や運動機能に合わせて、スタート前にモグラの顔出し時間（滞在時間）を3段階から選べるようにする。

| 速度モード | 通常滞在時間 | パニック時滞在時間 | 同時出現数 | 想定プレイヤー | 
| ----- | ----- | ----- | ----- | ----- | 
| **🐢 ゆっくり** | `1,800 ms` | `1,300 ms` | 1〜2匹 | シニア層、リハビリ、じっくり脳トレしたい方 | 
| **🐇 ふつう** *(既定)* | `1,250 ms` | `850 ms` | 1〜3匹 | 一般プレイヤー、心地よいテンポ感 | 
| **⚡ はやい** | `850 ms` | `550 ms` | 2〜4匹 | ゲーセン上級者、反射神経の限界挑戦 | 

### 5.3 ゲーム終了時のスコア履歴（Top 10 ランキング）＆ 今回順位ハイライト仕様（★v1.1追加）

ゲーム終了時（リザルト画面）に過去のスコア履歴（上限10件）を表示し、年配者でも**「今回の自分のスコアが何位に入ったのか」が一目で判別できる**UI/UXとデータ永続化を実装する。

#### ① データ保存・上限管理ルール（LocalStorage 永続化）
* **保存件数上限（Top 10）**: スコアの高い順にソートし、**上位10件（1位〜10位）のみ**を `localStorage` に保存する（11位以下は自動的に切り捨てる）。
* **同点時の優先順位**: 同スコアの場合は、**新しく達成した記録（今回のプレイ）を上位**に配置する。
* **ユニークIDによる今回判定**: ゲーム終了時に今回のレコードへ一意の `runId`（タイムスタンプ等）を付与して判定を行ってから上位10件を切り出すことで、同じ点数が複数あっても「今回の記録」の行を100%正確に特定する。

#### ② 「今回が何番目か」が一目でわかる3重の視覚ハイライト設計
1. **リザルト上部の特大ランクインバナー**:
   * Top 10入りした場合、最終スコアの直下に **`🎉 今回 第 3 位 ランクイン！`**（1位の場合は **`👑 祝・歴代 1 位（自己ベスト更新！）`**）という特大バナー（`22px〜28px` / `text-2xl`、鮮やかなゴールド枠＋黒背景または黄背景＋黒太字）を表示する。
   * 10位以内に入らなかった場合も、**`今回：圏外（あと ○○ 点で10位入り！）`** と目標がすぐわかるように大きく表示する。
2. **ランキング表における「今回行（Current Run）」の強調ハイライト**:
   * Top 10 リスト内の各行は最小フォントサイズ **18px〜20px (`text-lg`〜`text-xl`)** で描画し、今回の記録に該当する行（`record.id === currentRunId`）のみ以下の特別装飾を適用する：
     * **左端の目印バッジ**: 順位の横に **`👉 今回`** または **`★ NEW`** の高コントラストな黄色ピルバッジを表示。
     * **行全体の背景・枠線**: 他の過去履歴行を落ち着いた暗色（`bg-slate-900 text-slate-300`）にするのに対し、今回の行だけは**明るいアンバー背景＋太い黄色発光枠線（`bg-amber-500/25 border-2 border-yellow-300 text-white font-black`）**で囲み、緩やかなパルス演出を加える。
3. **自動スクロールフォーカス（`scrollIntoView`）**:
   * スマホ縦画面でランキング表がスクロール領域になる場合、リザルト画面が開いた瞬間に今回の順位の行へ自動スクロール（`el.scrollIntoView({ block: 'center', behavior: 'smooth' })`）させ、指で探さなくても必ず最初から画面中央に見えるようにする。

### 6.3 フルスクリーン切り替え機能

* ヘッダー右上に「全画面ボタン（⛶）」を配置。

* Android / PCブラウザでは `document.documentElement.requestFullscreen()`（解除時は `document.exitFullscreen()`）を呼び出す。

* iOS Safari（`requestFullscreen` 非対応環境）でタップされた場合は、「共有ボタン ➔『ホーム画面に追加』で全画面アプリとして遊べます」という大きな図解入り案内ポップアップ（3秒で自動消去またはタップで閉じる）を表示する。

### 6.4 Web Audio API ＆ 触覚フィードバック（Haptics）

* **AudioContextアンロック**: 最初の `pointerdown` イベントで `audioCtx.resume()` を確実に実行。

* **プロシージャル効果音**:

  * **出現音**: `240Hz ➔ 480Hz` サイン波（0.08s）

  * **打撃ヒット音**: `190Hz ➔ 540Hz ➔ 140Hz` トライアングル波＋ホワイトノイズ打撃アタック（0.15s、「ポカッ！」という小気味よい音）

  * **ヘルメット音**: `800Hz ➔ 960Hz` 矩形波（0.09s、「カン！」）

  * **お手つき・爆弾音**: `130Hz ➔ 40Hz` 下降ノコギリ波（0.28s、「ブブー / ドカン」）

  * **ルール変更ポップアップ音**: `[523Hz, 659Hz, 784Hz, 1046Hz]` の明瞭な注意喚起チャイム（0.35s）

* **バイブレーション（対応端末のみ）**:

  * ヒット時：`navigator.vibrate?.(15)`

  * お手つき・爆弾時：`navigator.vibrate?.([40, 30, 60])`

## 8. Antigravity エージェント向け実装着手順序

実装エージェントは以下のステップで段階的に構築・検証を進めること。

1. **Step 1: PWA基盤 ＆ Safe Area全画面レイアウトの構築**

   * `manifest.webmanifest`、メタタグ、`100dvh` ＋ `env(safe-area-inset-*)` コンテナの構築。

   * 320px（小型スマホ）〜タブレット・PCまで一切スクロールが出ず、かつ最小文字サイズが `16px` 以上であることを確認。

2. **Step 2: 高視認性3×3プレイフィールド ＆ モグラSVGコンポーネントの実装**

   * 3×3の穴と、高コントラストな大型数字プレートを持ったモグラSVG（通常・金・ヘルメット・爆弾）の実装。

   * タッチ遅延ゼロ（`pointerdown` 即時反応）のハンマー打撃エフェクトと浮き上がりスコア表示（`+10` / `×お手つき`）の実装。

3. **Step 3: ゲームループ・速度プリセット・「自動消去ポップアップ（Grace Pause）」の実装**

   * 「ゆっくり / ふつう / はやい」の速度制御。

   * ルール変更時およびパニックタイム突入時に、**1.5秒間ゲームを一時停止して画面中央に大型ポップアップを出し、自動で消えて再開する**シーケンスの実装。

4. **Step 4: Web Audio API サウンドエンジン ＆ Top 10 スコア履歴付きリザルト画面の実装**

   * 初回タップでの音声アンロック、各種シンセ効果音、クリア後の大型スコア表示。
   * `localStorage` を用いた Top 10 スコア履歴の保存（上限10件）と、リザルト表示時に「今回の順位バナー」およびリスト内の「`👉 今回` ハイライト行（自動中央スクロール付き）」の実装。
